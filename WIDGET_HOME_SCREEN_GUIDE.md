# Как добавить виджет на главный экран смартфона

## Требования

- ✅ Приложение **"Мысли в стопки"** установлено на смартфон
- ✅ Версия **1.4.0 или выше** (с поддержкой виджета)
- ✅ Android 5.0 или выше

## Пошаговая инструкция

### Способ 1: Через долгое нажатие на главный экран (Рекомендуется)

**Шаг 1:** Откройте главный экран смартфона
- Нажмите кнопку "Home" или проведите пальцем вверх с нижней части экрана

**Шаг 2:** Долгое нажатие на пустое место
- Нажмите и удерживайте палец на пустом месте главного экрана (2-3 секунды)
- Должно появиться контекстное меню

**Шаг 3:** Выберите "Виджеты" (Widgets)
- В меню выберите опцию "Виджеты" или "Add widgets"
- Откроется список доступных виджетов

**Шаг 4:** Найдите "Quick Task" виджет
- Прокрутите список и найдите виджет "⚡ Quick Task" или "Мысли в стопки"
- Иконка приложения должна быть рядом с названием

**Шаг 5:** Добавьте виджет
- Нажмите на виджет "Quick Task"
- Виджет будет добавлен на главный экран
- Если нужно, переместите его в удобное место

### Способ 2: Через меню приложений

**Шаг 1:** Откройте меню приложений
- Нажмите иконку "Приложения" (обычно в нижней части экрана)
- Или проведите пальцем вверх с нижней части экрана

**Шаг 2:** Найдите приложение "Мысли в стопки"
- Прокрутите список и найдите приложение
- Нажмите и удерживайте иконку приложения

**Шаг 3:** Выберите "Добавить виджет"
- В меню выберите "Add widget" или "Добавить виджет"
- Откроется список виджетов приложения

**Шаг 4:** Выберите "Quick Task"
- Нажмите на виджет "⚡ Quick Task"
- Виджет будет добавлен на главный экран

### Способ 3: Через параметры главного экрана (для некоторых телефонов)

**Шаг 1:** Откройте параметры главного экрана
- Долгое нажатие на главный экран
- Выберите "Параметры" или "Settings"

**Шаг 2:** Найдите опцию "Виджеты"
- В меню выберите "Виджеты" или "Widgets"

**Шаг 3:** Добавьте виджет приложения
- Найдите "Мысли в стопки" → "Quick Task"
- Нажмите "Добавить"

## Что произойдёт после добавления

### Внешний вид виджета

```
┌─────────────────────┐
│  ⚡ Quick Task      │
└─────────────────────┘
```

- **Размер:** Минимум 110dp × 40dp (примерно 2×1 клетка сетки)
- **Цвет:** Синий фон (#0a7ea4) с белым текстом
- **Иконка:** Молния (⚡)

### Как использовать виджет

**Шаг 1:** Нажмите на кнопку виджета
- Нажмите на кнопку "⚡ Quick Task" на главном экране

**Шаг 2:** Откроется окно создания задачи
- Приложение откроется с модальным окном быстрого создания задачи
- Это окно появится поверх главного экрана

**Шаг 3:** Введите название задачи
- Введите текст названия задачи в поле ввода

**Шаг 4:** Установите важность (1-7)
- Используйте ползунок "Важность"
- 1 = низкая важность, 7 = высокая важность

**Шаг 5:** Установите срочность (1-7)
- Используйте ползунок "Срочность"
- 1 = низкая срочность, 7 = высокая срочность

**Шаг 6:** Создайте задачу
- Нажмите кнопку "Создать задачу"
- Задача будет сохранена и добавлена в приложение

**Шаг 7:** Закройте окно
- Окно закроется автоматически
- Вы вернётесь на главный экран

## Управление виджетом

### Перемещение виджета

1. Нажмите и удерживайте виджет (2-3 секунды)
2. Перетащите его в новое место на главном экране
3. Отпустите палец

### Изменение размера виджета

1. Нажмите и удерживайте виджет (2-3 секунды)
2. Потяните за края виджета, чтобы изменить размер
3. Отпустите палец

**Примечание:** Размер виджета ограничен минимальными размерами. Если не получается изменить размер, это нормально.

### Удаление виджета

1. Нажмите и удерживайте виджет (2-3 секунды)
2. Выберите "Удалить" или "Remove"
3. Виджет будет удалён с главного экрана
4. Приложение остаётся установленным

## Решение проблем

### Проблема: Виджет не появляется в списке

**Решение:**
1. Убедитесь, что приложение установлено (версия 1.4.0+)
2. Перезагрузите смартфон
3. Откройте приложение хотя бы один раз
4. Попробуйте добавить виджет снова

### Проблема: При нажатии на виджет ничего не происходит

**Решение:**
1. Проверьте, что приложение не закрыто полностью
2. Откройте приложение вручную
3. Проверьте наличие интернета (для синхронизации)
4. Перезагрузите смартфон

### Проблема: Виджет показывает ошибку

**Решение:**
1. Удалите виджет с главного экрана
2. Переустановите приложение
3. Добавьте виджет снова

### Проблема: Задача не сохраняется

**Решение:**
1. Проверьте, что вы нажали "Создать задачу"
2. Проверьте наличие места в памяти смартфона
3. Откройте приложение и проверьте, появилась ли задача
4. Если нет — попробуйте создать задачу через приложение

## Советы по использованию

### Быстрое создание задач

- Используйте виджет для быстрого создания задач прямо с главного экрана
- Не нужно открывать приложение полностью
- Экономит время и батарею

### Оптимальное размещение

- Поместите виджет в верхнюю часть главного экрана для быстрого доступа
- Или разместите рядом с часами и погодой

### Синхронизация

- Задачи, созданные через виджет, автоматически синхронизируются с приложением
- Открыв приложение, вы увидите все созданные задачи

### Несколько главных экранов

- Вы можете добавить виджет на несколько главных экранов
- Каждый виджет работает независимо

## Дополнительная информация

### Что такое виджет?

Виджет — это небольшое приложение, которое работает прямо на главном экране смартфона. Оно позволяет быстро выполнять действия без открытия полного приложения.

### Преимущества виджета

- ⚡ **Быстрый доступ** — создавайте задачи за 5 секунд
- 📱 **На главном экране** — всегда видно и доступно
- 🔄 **Синхронизация** — задачи автоматически добавляются в приложение
- 💾 **Сохранение** — все задачи сохраняются в базе данных
- 🎨 **Тема** — виджет автоматически адаптируется к теме смартфона

### Безопасность

- Виджет работает локально на вашем смартфоне
- Данные не отправляются на внешние серверы
- Все задачи хранятся в зашифрованной базе данных
